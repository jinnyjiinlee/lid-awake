Four safety nets, in case you forget

뚜껑 닫힌 채 가방에 넣으면 뜨거워질 수 있어요. 그래서 알아서 꺼지게 만들었어요.

A closed MacBook in a bag can get hot. So LidAwake turns itself off.

1
시간 정해서 켜기Timer 1·2·4·8시간 뒤 자동으로 꺼져요. 남은 시간은 메뉴바에 보여요. Turns off after 1, 2, 4 or 8 hours. Time left shows in the menu bar.
2
배터리 20% 이하면 끄기Low battery 충전기 없이 배터리가 떨어지면 자동으로 꺼지고 알려 줘요. Turns off and notifies you when battery drops below 20%.
3
뜨거워지면 끄기Heat guard 맥이 과열 상태가 되면 바로 꺼져요. Turns off right away if your Mac overheats.
4
상태가 늘 보여요Always visible 해 = 켜짐, 달 = 꺼짐. 켜둔 채 앱을 끄려 하면 한 번 더 물어봐요. Sun = on, moon = off. Asks before quitting while on.

설치하기

Install

둘 중 편한 방법으로 하세요. 1분이면 끝나요.

Pick whichever is easier. Takes a minute.

방법 1. 한 줄 설치Option 1. One line추천Recommended

터미널을 열고(⌘ + 스페이스 → "터미널") 아래 한 줄을 붙여넣고 엔터. 경고창 없이 바로 설치돼요.

Open Terminal (⌘ + Space → "Terminal"), paste this line and press Return. No warning dialogs.

curl -fsSL https://getlidawake.vercel.app/install.sh | bash

방법 2. 직접 다운로드

Option 2. Download

  1. LidAwake.zip 받아서 더블클릭
  2. LidAwake를 응용 프로그램 폴더로 옮기기
  3. 앱을 열면 "확인할 수 없음" 경고 → 완료
  4. 시스템 설정 → 개인정보 보호 및 보안 맨 아래 그래도 열기
  1. Download LidAwake.zip and double-click it
  2. Move LidAwake to Applications
  3. Open it. If macOS warns, click Done
  4. System Settings → Privacy & Security → Open Anyway

FAQ

안전한가요?Is it safe?

소스 코드가 GitHub에 전부 공개돼 있어요. 앱이 관리자 권한으로 하는 일은 딱 두 가지예요. 잠자기 끄기(pmset disablesleep 1)와 켜기(0). 다른 명령은 실행하지 않아요.

All source code is public on GitHub. The only privileged commands it runs are pmset disablesleep 1 and 0. Nothing else.

왜 경고창이 뜨나요?Why does macOS show a warning?

애플 유료 개발자 서명을 하지 않은 무료 앱이라서 그래요. 한 줄 설치를 쓰면 경고 없이 설치돼요.

It's a free app without a paid Apple signature. The one-line install avoids the warning.

뚜껑 닫으면 화면은요?What about the screen?

화면은 꺼지고 본체만 계속 돌아가요. 뚜껑을 열면 바로 이어서 쓸 수 있어요.

The screen turns off; the Mac keeps running. Open the lid and you're right back.

메뉴바에 아이콘이 안 보여요.I can't see the menu bar icon.

메뉴바 아이콘이 많으면 노치 뒤로 가려질 수 있어요. 그럴 땐 응용 프로그램에서 LidAwake를 다시 열면 켜기·끄기 창이 떠요.

With many menu bar icons it can hide behind the notch. Open LidAwake again from Applications to get the on/off window.

지우려면요?How do I uninstall?

메뉴에서 끄기 → 비밀번호 없이 쓰기 해제 → 종료. 그다음 응용 프로그램 폴더에서 LidAwake를 휴지통으로 옮기면 끝.

Turn off → Require password again → Quit, then move LidAwake from Applications to the Trash.
